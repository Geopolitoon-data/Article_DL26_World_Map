# Digital Leaders 2026 scrollytelling story

A scroll-driven version of the *"Where does the digital economy go to school?"* article,
built to sit on the Emerging website next to the interactive World Map.

    index.html            the story (structure + copy)
    styles.css            Emerging brand tokens, single light theme, responsive
    story.js              step detection, the native waffle chart, progress bar
    data/story-data.json  the 200 Global-ranked institutions (country, region, type, rank)
    assets/*.png          the 14 article figures, 200 dpi, transparent background
    build_standalone.py   inlines everything into dist/dl2026-story.html
    dist/                 generated - do not edit by hand

## Running it locally

The page reads `data/story-data.json`, so it needs a server. Opening `index.html`
straight off disk will leave the waffle chart empty.

```
E:
cd dl2026_scrolly
python -m http.server 8010
```

Then open <http://localhost:8010/index.html>.

## Publishing

Two routes, same as the World Map:

1. **Folder.** Push this directory and serve `index.html`. Everything it needs is
   inside the folder; there are no external dependencies except the Google Fonts
   stylesheet for Montserrat.
2. **Single file.** `python build_standalone.py` produces `dist/dl2026-story.html`
   with the CSS, JS, data and all images inlined as base64 (~2.0 MB). Use this for a
   Webflow embed or anywhere a strict CSP blocks `fetch()` and sibling assets.

## How it is built

**The pattern is sticky-figure-with-stepped-text.** Each chapter is a two-column grid:
narrative steps on the left, a graphic pinned on the right. One step makes exactly one
visible change to the graphic, which is the rule that keeps the scroll feeling earned
rather than decorative.

**Step detection uses IntersectionObserver as a trigger and measurement as the
decision.** Reacting to observer entries directly is fragile. On a jump (an anchor
link, a keyboard PageDown, a restored scroll position) several steps enter and leave
in a single batch, and whichever entry is processed last wins, which is not
necessarily the step the reader is looking at. `activate()` therefore measures every
step in the block against the viewport centre and picks the nearest. It is a handful
of rect reads, runs only on observer callbacks, and is always right.

**The sticky graphic must be shorter than one step** (86vh against 100vh). If the
graphic is taller than the step column beside it, sticky positioning has no room to
work and the graphic scrolls away, leaving what looks like a blank page.

**The figures are transparent, and the page is white.** There is no card, border
or shadow behind a graphic - that reads as a slide pasted onto a page rather than a
figure belonging to it. The web set in `assets/` is regenerated with
`DL_FIG_TRANSPARENT=1`, so the page background shows through the figure and the
graphics blend into whatever the host page provides. The print set in
`E:\dl2026_infographics` is unchanged and still drawn on white, which is what Word,
PowerPoint and Canva need.

**Chapter 3 draws its own chart.** The waffle, 200 squares, one per Global-ranked
institution, is built in SVG from `story-data.json` and recoloured in place across
three steps: by country, then region, then institution type. Same 200 squares, three
questions. This is the part worth extending: every other graphic is a flat PNG, so it
cannot respond to the reader.

## Known limitations

- **The page is deliberately light-only.** The figures are transparent PNGs carrying
  dark navy type, so they only read on a light ground. Supporting a dark theme means
  generating a second set of figures, not swapping CSS tokens.
- **The PNG figures are raster.** They will not restyle, animate or respond to hover.
  Porting them to SVG or to live D3 (as the World Map already does) is the obvious
  next step if this format is adopted.
- **The CTA at the end has a placeholder `href`.** Point it at the published map.
- **Copy is the article's, lightly cut for scroll.** Any change to the article should
  be mirrored here; the figures themselves are regenerated by
  `E:\dl2026_infographics\_build\figs_a.py` / `figs_b.py`.

## Accessibility

Every step's insight is carried in the text, so nothing is lost if the graphics do not
load. There is no scroll hijacking. The page uses native scrolling throughout, so
Space, PageDown and the arrow keys behave normally. `prefers-reduced-motion` drops the
cross-fades and the scroll cue.
